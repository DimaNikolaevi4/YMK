## 2. Структура раздатки (порядок блоков фиксированный)

```text
1. Шапка (без титульного листа), выравнивание СЛЕВА, без отступа,
   пустая строка после шапки НЕ ставится:
     ПРАКТИЧЕСКАЯ РАБОТА № <N>                          (14 pt, полужирный)
     ПМ.02 «<наименование ПМ>»                          («ПМ.02» полужирный)
     МДК <код> «<наименование МДК>»                     («МДК <код>» полужирный)
     Профессия <код> <наименование>                     («Профессия <код>» полужирный)
     Группы <группы> · <курс> курс · <семестр> семестр  («Группы …» полужирный)
     Количество часов: <N>                              (целиком полужирный)

2. Тема:            — дословно из КТП (Т2, колонка 2); метка «Тема:» полужирная
3. Цель работы:     — по типу работы (см. §2.1); метка полужирная
4. Оборудование:    — одна строка: «Письменные принадлежности, листы А4.»
5. Краткая теория:  — заголовок полужирный; содержание по типу работы (§2.1);
                      ссылки только на действующие НТД РФ
6. Пример оформления (заполнения) документа: — заголовок полужирный;
                      образец той формы, которую студент заполняет
                      (абзац-«как пользоваться» + таблица-образец с первой
                      строкой-образцом и пустыми строками под заполнение)
7. Варианты задания (исходные данные): — ⭐ только ДЛЯ РАБОТ С ВАРИАНТАМИ;
                      минимум 2 варианта («Вариант 1…», «Вариант 2…»), полный
                      состав данных; для работ, не зависящих от варианта
                      (ознакомительных), блок пропускается целиком
8. Ход работы:      — нумерованные пункты «1. …» «2. …»; без шагов-«пустышек»;
                      по процессу: ознакомиться → подготовить ответы на
                      контрольные вопросы → оформить отчёт (рукопись на А4,
                      по ЕСКД, строго по последовательности пунктов)
9. Содержание отчёта: — перечень элементов отчёта в нужной последовательности
                      (заголовок «Практическая работа № N»; тема; цель;
                      краткая теория; таблица — с правилом заполнения; вывод)
10. Контрольные вопросы: — 3–5 вопросов, каждый нумеруется «1. …» и т. д.
                      (защита устная, в конце занятия; на лист студента
                      не переписывается)
11. Литература:     — действующие НТД РФ + источники КТП с индексами «ОИ1.»,
                      «ДИ1.» (с точкой); без нумерации
```

### 2.1. Два рабочих формата раздатки

**А. Ознакомительный (реализован в ПР № 1 — для слабой группы, 1 час):**
- цель — «ознакомиться …; переписать краткую теорию; заполнить таблицу по образцу; сделать вывод»;
- теория — **готовые пункты для переписывания** (5–6 пунктов, по 1–2 строки);
- задание — через **банк слов**: количество слов в банке = числу пустых ячеек таблицы (соответствие 1:1); в таблице первая строка — заполненный образец;
- вывод — **готовое предложение** для переписывания;
- внизу листа студента — строка «Выполнил: студент группы ____ ФИО ____ Дата: ____» (таблицы реквизитов не используется);
- блоки «Варианты задания» нет.

**Б. С вариантами (каркас для последующих работ — по команде владельца):**
- блок 6 строится по разбору **варианта 0** (студентам не выдаётся): исходные данные варианта 0 → полностью заполненные итоговые таблицы (без пустых строк) → таблицы «Пояснения к заполнению граф» (по каждой графе — правило, откуда берётся значение; первая строка — «Реквизиты листа»);
- блок 7 — минимум 2 варианта, каждый полным составом данных (оборудование/линии связи; монтажная организация; проектные документы с шифрами; сроки работ; строка «Задание студенту»); значения не совпадают с вариантом 0;
- критерий исходного варианта: все графы форм заполняются из варианта без домысливания.

**Общее для обоих форматов:**
- вся раздатка выдаётся студенту целиком; на отдельный лист А4 студент переписывает только то, что прямо помечено (пункты теории, задание, банк слов, таблицу, вывод);
- **не писать** отдельный блок «структура/требования к оформлению листа студента» — порядок переписывания задаётся «Ходом работы» и пометками прямо в тексте (отдельный блок вносит путаницу);
- лист студента должен умещаться на **одной странице А4** — от руки;
- реквизиты: в ознакомительном формате — строка «Выполнил…»; в формате с вариантами — небольшая таблица («Разработал», «Проверил», «Дата») внизу листа;
- «Содержание отчёта» (ознакомительный формат) — перечень элементов, без лишних обобщений.

## 3. Правила оформления .docx (§ — единый стандарт)

**Страница и шрифт:**
- формат **А4** (21,0 × 29,7 см); ⚠ не оставлять Letter 21,6 × 27,9;
- поля: левое 3 см, правое 1,5 см, верхнее 2 см, нижнее 2 см;
- Times New Roman, 12 pt; шапка-заголовок «ПРАКТИЧЕСКАЯ РАБОТА № N» — 14 pt полужирный;
- межстрочный интервал **1,15** (в стиле Normal; прямых переопределений на «1.0» в абзацах не оставлять);
- абзацный отступ первой строки 1,25 см (для текстовых абзацев и пунктов-перечислений теории; у шапки, заголовков и нумерованных шагов отступа нет).

**Заголовки и шапка:**
- заголовки блоков («Тема:», «Цель работы:», «Оборудование:», «Краткая теория:», «Пример оформления (заполнения) документа:», «Ход работы:», «Содержание отчёта:», «Контрольные вопросы:», «Литература:») — **полужирные, с двоеточием**, отдельной строкой, без нумерации, без отступа; полноформатное единообразие (нельзя, чтобы часть заголовков была обычным шрифтом);
- в строках шапки полужирный — начальный фрагмент (метка), остальное обычным; «Количество часов: N» — полужирный целиком; «Тема:», «Цель работы:», «Оборудование:» — метка полужирная, текст обычным.

**Списки и вопросы:**
- пункты «Хода работы» — абзацы с текстом «1. …», «2. …» (отступ первой строки не ставить);
- контрольные вопросы — каждый с номером «1. …», «2. …»;
- элементы «Содержания отчёта» — короткие абзацы-перечисления (по формулировкам владельца), в конкретной последовательности;
- литература — без нумерации, каждый источник отдельной строкой.

**Таблицы:**
- стиль **Table Grid** (видимые границы), Times New Roman 10 pt;
- шапка таблицы — полужирная; подпись над таблицей полужирным (10–12 pt); после таблицы — пустой абзац;
- без заливок ячеек, без объединённых ячеек, без границ страницы.

**Текст и стилистика:**
- кавычки — «ёлочки», тире — длинное (—), без двойных пробелов;
- «организационно-технологическая» — всегда через дефис;
- «Содержание отчёта», «отчёт» — с ё;
- индексы источников литературы — с точкой: «ОИ1.», «ДИ1.», «ЭИ1.»;
- без лишних/дублирующих запятых («нужна для», «монтажу, наладке»);
- генератор автоматически: нумерация вопросов и пунктов хода работы; ручная сборка — сверять по этому §3 (последняя сверка ручной версии № 1 — 2026-11-03: A4, 1,15, полужирные заголовки, вопросы 1–5).

## 6. Скелет data-JSON (эталон формата)

```json
{
  "mdk_code": "02.01",
  "mdk_name": "Наладка приборов систем автоматики",
  "pm_code": "ПМ.02",
  "pm_name": "Ведение наладки, юстировки и сдача в эксплуатацию контрольно-измерительных приборов и электрических схем систем автоматики",
  "profession": "15.01.37 Слесарь-наладчик контрольно-измерительных приборов и автоматики",
  "groups": "С-21, С-22",
  "course": 2,
  "semester": 3,
  "filename_suffix": "С-21-22",
  "works": [
    {
      "number": 1,
      "hours": 1,
      "topic": "…(дословно из КТП)",
      "goal": "…",
      "equipment": "Письменные принадлежности, листы А4.",
      "theory": ["абзац 1", "пункт 2", "…"],
      "sample": [
        {"type": "p",     "text": "…"},
        {"type": "table", "caption": "…", "headers": ["…"], "rows": [["…"], ["", ""]]}
      ],
      "variants": [],
      "steps": ["1-й шаг", "2-й шаг", "…"],
      "report":   ["…"],
      "questions":["…"],
      "literature":["действующие НТд РФ…", "ОИ1. …", "ДИ1. …"]
    }
  ]
}
```

> `sample`/`variants` — списки элементов `{"type": "p" | "table", …}`; у таблиц ключи `caption`, `headers`, `rows`. Пустой `variants` = блок пропускается (ознакомительный формат). В «работах с вариантами» `sample` включает исходные данные варианта 0, полностью заполненные итоговые таблицы и «Пояснения к заполнению граф».
