# ПРАКТИЧЕСКИЕ_INSTRUCTIONS.md — методика разработки практических работ

**Роль файла:** 🤖 СЦЕНАРИЙ + методика третьего направления репозитория («ПРАКТИЧЕСКИЕ РАБОТЫ»). Адресован ИИ-агенту и владельцу. Создание документа — по шагам, стресс-тест эталона — после правок владельца.

**Статус:** принято решение владельца (2026-11-02):
- формат итоговых документов — **только .docx** (генерация через `scripts/generate_practical_compact.py`);
- первая партия — **только КТП МДК 02.01 С-21-22, 2 курс** (7 работ, 12 часов);
- заголовок документа — **«Практическая работа № N»** (пример стиля — файл `E:\Бардаков ПР МДК 03.02 3 КУРС.doc` владельца, работа № 1, про OpenProj);
- контрольные вопросы и литература — **в конце** документа (вопросы = вопросы для защиты, форма контроля КТП — «Защита пр.раб.»).

**Решения по эталону № 1 (видовые правки владельца, 2026-11-02 — действуют для всех работ):**
- Шапка: первой строкой после «ПРАКТИЧЕСКАЯ РАБОТА № N» идет **ПМ.02 «…»**, затем **МДК 02.01 «название»** — одной строкой, в кавычках (не двумя строками).
- Шапка: **выравнивание слева**; начальный фрагмент каждой строки полужирный («ПМ.02», «МДК 02.01», «Профессия 15.01.37», «Группы С-21, С-22»), «Количество часов: N» — целиком полужирный; **пустая строка между шапкой и «Тема» не ставится**.
- «Оборудование:» — **только письменные принадлежности и листы А4** (слово «тетрадь» не используется).
- ⭐ Перед заданием («Ходом работы») обязателен блок **«Пример оформления (заполнения) документа:»** — разбор по **варианту 0** (студентам не выдается): исходные данные варианта 0, полностью заполненные итоговые таблицы (без пустых строк) и таблицы **«Пояснения к заполнению граф»** — по каждой графе правило, откуда берётся значение. Критерий: студент заполняет такие же формы по своему варианту без вопросов.
- Объём работы — **на один аудиторный час**; раздаточный материал — несколько листов (пример, варианты и т. д.), а **результат студента — один лист А4**. Сверху вниз на листе студента: 1) «Практическая работа № N»; 2) тема и цель (переписать из раздатки); 3) краткая теория 1–2 строки; 4) таблица «Перечень заданий…» (2–3 строки); 5) таблица «Перечень материалов…» (2–3 строки); 6) внизу — таблица реквизитов («Разработал», «Проверил», «Дата») и вывод (1–2 предложения). Итоговые таблицы примера (вариант 0) и студенческие — **2–3 строки** (большие перечни не успеть за час); таблицы-данные вариантов (исходники) не сокращаются. Реквизиты — одной небольшой таблицей внизу листа (решение владельца 2026-11-02); в таблице «Пояснения к заполнению граф» первая строка — «Реквизиты листа».
- ⭐ После блока «Пример оформления» обязателен блок **«Варианты задания (исходные данные):»** — **минимум два варианта** («Вариант 1», «Вариант 2»), каждый — полным составом данных: оборудование и линии связи (марки/сечения, длины, точки подключения), монтажная организация (звенья, бригадиры), проектные документы (шифр, листы), сроки работ, строка «Задание студенту». Варианты должны быть **корректны по критерию полноты**: все графы заполняются из данных варианта без домысливания; значения не совпадают с вариантом 0 (чтобы нельзя было списать).
- **Раздатка едина (2026-11-03):** готовится ОДИН документ, который выдаётся студенту целиком; отдельного «преподавательского» экземпляра НЕТ. Контрольные вопросы (устная защита в конце занятия) и литература остаются в конце той же раздатки — студент их читает, но не переписывает.
- **Ознакомительный формат для слабой группы (ПР № 1, 2026-11-03):** тема не меняется; цель — «ознакомиться / переписать теорию / заполнить таблицу по образцу / сделать вывод»; теория — 5 готовых пунктов для переписывания + пояснения с обязательной пометкой «переписывать НЕ нужно»; задание — через **банк слов** (число слов = числу пустых строк таблицы, соответствие 1:1); первая строка таблицы — заполненный образец; вывод — готовое предложение для переписывания; внизу листа студента — строка «Выполнил: студент группы ____ ФИО ____ Дата: ____» (таблица реквизитов НЕ используется).
- **Блок «Варианты задания» — опционален:** если работа не использует варианты (как № 1), блок пропускается целиком (генератор поддерживает пустой `variants`). Блок-описание «структура листа студента» в раздатку НЕ включается (вносит путаницу — решение владельца 2026-11-03); «Содержание отчета» — одна строка без перечислений: «Один лист А4, заполненный от руки по этой раздатке».
- Нормативная база — **только документы, действующие на территории РФ** (см. §1, строку «Действующая НТД»); устаревшие СНиП/ВСН в качестве первичных ссылок не использовать.

## 2. Структура документа (фиксированная, 10 блоков)

```text
1. Шапка (без титульного листа) — выравнивание СЛЕВА, пустая строка после не ставится:
   ПРАКТИЧЕСКАЯ РАБОТА № <N>                                  (14 pt, полужирный)
   ПМ.02 «<наименование ПМ>»                                  (метка «ПМ.02» полужирная)
   МДК 02.01 «<наименование МДК>»                             (метка «МДК 02.01» полужирная, одной строкой)
   Профессия <код> <наименование>                             (метка «Профессия <код>» полужирная)
   Группы <группы> · <курс> курс · <семестр> семестр          (метка полужирная)
   Количество часов: <N>                                      (целиком полужирный)

2. Тема: «…»                 — точная формулировка из колонки 2 Т2 КТП
3. Цель работы:              — глаголы совершенного вида («составить», «научиться»)
4. Оборудование:             — одна строка: «Письменные принадлежности, листы А4.»
5. Краткая теория:           — 2–4 абзаца, строго прикладные: только те понятия,
                               формы и реквизиты, которые реально используются
                               в образце и «Ходе работы»; ссылки на ДЕЙСТВУЮЩУЮ НТД РФ
                               (обозначение СП/ГОСТ + название + «актуализированная
                               редакция СНиП …»), приложения с формами — поименно.
6. Пример оформления (заполнения) документа: ⭐ ОБЯЗАТЕЛЕН
                             — первые два абзаца: (а) вариант 0 студентам не
                               выдается, свои таблицы студент заполняет данными
                               только своего варианта; (б) ПРАВИЛО ЛИСТА
                               СТУДЕНТА — результат работы ОДИН лист А4,
                               сверху вниз: «Практическая работа № N» → тема
                               и цель (из раздатки) → краткая теория 1–2
                               строки → таблица «Перечень заданий…» (2–3
                               строки) → таблица «Перечень материалов…» (2–3
                               строки) → внизу таблица реквизитов и вывод
                               (1–2 предложения).
                               затем: исходные данные варианта 0 → полностью
                               заполненные примеры ИТОГОВЫХ таблиц (2–3 строки
                               каждая, пустых строк нет) → таблицы «Пояснения
                               к заполнению граф» (первая строка — «Реквизиты
                               листа», дальше — по каждой графе правило,
                               откуда берётся значение) → одна небольшая
                               таблица реквизитов, заполненная по варианту 0
                               (образец для листа студента).
                               Критерий: студент, взявший свой вариант, вычерчивает
                               и заполняет свой лист А4 БЕЗ вопросов к
                               преподавателю.
7. Варианты задания (исходные данные): ⭐ ДЛЯ РАБОТ С ВАРИАНТАМИ (минимум 2;
                               для вариативности-независимых работ, как
                               ознакомительная № 1, блок пропускается целиком)
                             — вводный абзац (вариант 0 — только для примера;
                               заполнять только данными своего варианта) →
                               таблицы «Вариант 1. Объект …», «Вариант 2. …».
                               Состав каждой строки варианта (един для всех):
```

Блоки 2–9 — до отчета, блоки 10–11 — в конце (решение владельца). В шапке нет имени преподавателя (в примере реквизитов блока 6 — допустимо, как учебный пример).

> Ознакомительная работа (как № 1, 2026-11-03): блока «Варианты задания» может не быть; «Содержание отчета» — одна строка («Один лист А4, заполненный от руки по этой раздатке»); блок-описание «структура листа студента» НЕ пишется — порядок переписывания задается «Ходом работы» и пометками «задание для переписывания» / «переписывать НЕ нужно» прямо в тексте.

> **Правило таблиц листа студента.** Для ПР № 1 (монтажные работы) итоговые таблицы — «Перечень заданий электромонтажникам» и «Перечень применяемых материалов и изделий». В перечень материалов входят **только кабели** (одна строка на марку); кабельные конструкции, трубы и арматуру в перечень не включают — они принимаются по спецификации проекта (правило записано и в графе «Количество» таблицы пояснений). Для ПР № 2–7 (акты и протоколы приёмки) каркас листа тот же, но таблицы называются по документу: реквизиты акта (протокола) → перечень (оборудование, проверяемые функции, показатели — 3 строки) → результаты (испытаний, замечания, приложения — 3 строки) → заключение → таблица реквизитов внизу и вывод.

## 3. Правила оформления .docx

- Times New Roman, 12 pt (шапка-заголовок «ПРАКТИЧЕСКАЯ РАБОТА № N» 14 pt);
- шапка: выравнивание слева, начальный фрагмент каждой строки полужирным,
  «Количество часов» целиком полужирным; пустая строка после шапки НЕ ставится;
- A4, поля: левое 3 см, правое 1,5 см, верхнее 2 см, нижнее 2 см;
- межстрочный интервал 1,15; абзацный отступ первой строки 1,25 см;
- заголовки блоков — полужирным, отдельной строкой, без нумерации;
- нумерованные пункты «Хода работы» — обычные абзацы с текстом «1. …», «2. …»;
- **таблицы-образцы в блоке 6**: стиль «Table Grid» (видимые границы), TNR 10 pt,
  подпись таблицы над таблицей полужирным, шапка полужирным, после таблицы пустой абзац;
- без заливок ячеек, без титульного листа и границ страницы.
