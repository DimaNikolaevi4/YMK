# Утилиты поиска литературы (ИЭЙН / РГБ)

Здесь лежат скрипты для поиска книг в каталогах **ИЭЙН** (ищи-2, ищи-3) и **РГБ**.
Используются преподавателем вручную для актуализации списка литературы в КТП.

## Состав

### `ishi2_*.py/.sh` (6 файлов) — поиск в ИЭЙН версия 2
- `ishi2_search.py` / `ishi2_search.sh` — поиск книг по ключевым словам
- `ishi2_fetch.py` / `ishi2_fetch2.py` — загрузка найденных страниц
- `ishi2_registries.py` — работа с реестрами найденного
- `ishi2_review.py` — ревью найденного

### `ishi3_*.py/.sh` (5 файлов) — поиск в ИЭЙН версия 3
- `ishi3_search.py` / `ishi3_search.sh` — поиск
- `ishi3_fetch.py` — загрузка
- `ishi3_registries.py` — реестры
- `ishi3_extract_toc.py` — извлечение оглавлений

## Использование

```bash
python3 scripts/_utils/ishi3_search.py "автоматизация технологических процессов"
bash scripts/_utils/ishi3_search.sh "монтаж систем автоматизации"
```

Результаты поиска сохраняются в `scripts/lit_pages_*.json` (в корне scripts/).
