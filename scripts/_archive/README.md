# Архив одноразовых скриптов

Здесь лежат скрипты, выполненные для разовых правок КТП/JSON в прошлых итерациях.
Они **не запускаются регулярно** — их результат уже зафиксирован в `.docx`/`.json` файлах
в `KTP/` и `scripts/data_*.json`.

## Состав

### `fix_*.py` (6 файлов) — одноразовые правки
- `fix_book_vars.py` — правка переменных книг в JSON
- `fix_col8_col9_split.py` — разделение колонок 8/9 (оборудование/задание)
- `fix_owner_decision_46plus2.py` — правка по решению владельца (46+2 часов)
- `fix_t1_t2_format.py` — формат таблиц Т1/Т2
- `fix_theory_word.py` — правка слова «теория» в темах
- `fix_uploaded_ktp.py` — правка загруженного КТП

### `rebuild_table2_v*.py` (2 файла) — старые версии
- `rebuild_table2_v2.py`, `rebuild_table2_v3.py` — предыдущие итерации
  пересборки Таблицы 2. **Актуальная версия:** `scripts/rebuild_table2.py` (в корне).

### `search_got_step*.py` (7 файлов) — одноразовый процесс поиска
- `search_got_files.py`, `search_got_step2..7.py` — пошаговый процесс поиска
  GOT-файлов (graphic output table). Результат зафиксирован в JSON данных.

## Использование

Если нужно перезапустить один из этих скриптов (например, после обновления РП):
```bash
python3 scripts/_archive/fix_col8_col9_split.py
```
Но обычно это не нужно — правки уже применены к текущим `.docx`/`.json`.
