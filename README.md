## О проекте

Репозиторий изначально создавался для автоматической генерации **календарно-тематических планов (КТП)** по МДК на основе рабочих программ (РП). В ходе работы выяснилось, что накопленная методическая база (эталоны оформления, валидаторы, скрипты, форматы данных) одинаково применима и к другим типам методических документов, которые преподаватель СИТ готовит к промежуточной и итоговой аттестации.

Поэтому сфера репозитория **расширена** и теперь покрывает два параллельных направления:

| Направление | Документ | Эталон | Инструкции | Скрипты |
|---|---|---|---|---|
| **КТП** | Календарно-тематический план по МДК | `KTP/КТП МДК 05.02 М 2 курс.docx` | [`создание_КТП.md`](создание_КТП.md), [`KTP_INSTRUCTIONS.md`](KTP_INSTRUCTIONS.md), [`logic.md`](logic.md) | `scripts/generate_ktp_docx.py`, `scripts/validate_ktp.py` |
| **ПЕРЕЧЕНЬ МАТЕРИАЛОВ** | Перечень материалов для подготовки студентов к промежуточной аттестации | `Перечни/перечень ПМ 02 МДК 02.01.docx` (наиболее полный) | [`ПЕРЕЧЕНЬ_INSTRUCTIONS.md`](ПЕРЕЧЕНЬ_INSTRUCTIONS.md) | _планируется `scripts/generate_perechen_docx.py`_ |

**Учебное заведение:** ГБПОУ РО «Сальский индустриальный техникум» (СИТ).
**Специальность:** 15.02.07 «Автоматизация технологических процессов и производств (по отраслям)».

## Направление 1 — КТП (календарно-тематический план)

### Единственный эталон

**`KTP/КТП МДК 05.02 М 2 курс.docx`** — золотой стандарт оформления. Любой сгенерированный КТП должен быть структурно идентичен ему:

- Титульный лист: `МИНИСТЕРСТВО ОБРАЗОВАНИЯ РОСТОВСКОЙ ОБЛАСТИ` (без «общего и профессионального»)
- **7 таблиц**: УТВЕРЖДАЮ (без рамки), Таблица 1, Таблица 2, 2а, 2б, 2в, 2г
- **Таблица 1** — распределение часов: 12 колонок, 4-строчная шапка с объединениями, 12 строк
- **Таблица 2** — содержание обучения: **11 колонок** (включая ОК, ПК, ФИО преподавателя), шапка 3 строки + номерная
- **Таблица 2г (ЭИ)** — электронные источники с 5-й колонкой `URL (ссылка)`
- **Без заливки ячеек** (все ячейки белые), Times New Roman: титульник 12pt, таблицы 10pt
- Строка аттестации в Таблице 2: номер, название, 2 часа — остальные графы пустые

### Как сгенерировать КТП (для ИИ-ассистента)

1. **Прочитать инструкции:** `создание_КТП.md` (главная методика), `KTP_INSTRUCTIONS.md` (шаги), `logic.md` (логика).
2. **Изучить эталон:** `KTP/КТП МДК 05.02 М 2 курс.docx` — структура, шрифты, тексты шапок.
3. **Изучить шаблоны:** `template_ktp.md`, `sample_ktp_example.md`.
4. **Извлечь данные из РП** (`RP/`): темы, часы, занятия, литература, оснащение.
5. **Подготовить JSON** в формате `scripts/data_05_02_example.json`. Ключевые поля часов (источник — строка «МДК …» тематического плана РП, раздел 3):
   - `total_hours` — кол. 3 строки МДК (для МДК 05.02: 112);
   - `practice_hours` — кол. 4 строки МДК («в форме практической подготовки»);
   - НЕ путать: 96 = 60 + 36 уч. практики — по разделу целиком (РП, табл. 3.1); практика планируется отдельно и на титул КТП не попадает.
   - Слово «час» в титуле склоняется автоматически (8→часов, 2→часа, 60→часов).
6. **Сгенерировать:**
   ```bash
   python3 scripts/generate_ktp_docx.py --data data.json --output "KTP/КТП МДК 05.02 М3 курс.docx"
   ```
7. **Провалидировать (обязательно):**
   ```bash
   python3 scripts/validate_ktp.py --doc "KTP/КТП МДК 05.02 М3 курс.docx" --data data.json
   ```
8. **Сохранить** с именем `КТП МДК [код МДК] М[номер курса] курс.docx` в `KTP/`.

## Направление 2 — ПЕРЕЧЕНЬ МАТЕРИАЛОВ

### Что это за документ

«Перечень материалов для подготовки студентов к промежуточной аттестации» — обязательный методический документ СИТ, оформляется на каждый МДК отдельно. Содержит:

1. **Титульный блок** — шапка Министерства, УТВЕРЖДАЮ, заголовок «ПЕРЕЧЕНЬ МАТЕРИАЛОВ», учебный год, МДК, специальность, группа, преподаватель, согласование с ЦК.
2. **Контроль знаний** — таблица: форма контроля (диф. зачёт / защита курсового проекта / экзамен квалификационный), раздел, сроки по урокам.
3. **Требования к результатам освоения** — структурированный блок «иметь практический опыт / уметь (обязательная часть) / уметь (вариативная часть) / знать (обязательная) / знать (вариативная)».
4. **Перечень самостоятельных, практических и лабораторных работ** — большая таблица с разделами МДК, темами, практическими работами, лабораторными и самостоятельными работами.
5. **Вопросы к дифференцированному зачёту** (или курсовое проектирование).
6. **Критерии оценки знаний студентов** (5/4/3/2).
7. **Лист ознакомления студентов** — таблица ФИО / Дата / Подпись по каждой группе.

### Образцы

В папке [`Перечни/`](Перечни/) лежат 4 эталонных образца, охватывающих разные варианты документа. Каждый файл хранится в двух форматах: `.doc` (оригинал) и `.docx` (сконвертирован для парсинга через `python-docx`).

| Файл | МДК | Особенности |
|---|---|---|
| `перечень ПМ 02 МДК 02.01.doc`/`.docx` | ПМ.02 МДК 02.01 | Самый полный: есть курсовое проектирование + лист ознакомления по 2 группам |
| `перечень МДК 03.01.doc`/`.docx` | ПМ.03 МДК 03.01 | Компактный: только диф. зачёт, 1 группа |
| `перечень заданий ПМ05 01 2019.doc`/`.docx` | МДК 05.01 | Только практические работы + 20 вопросов к зачёту |
| `перечень заданий ПМ05 02 2019.doc`/`.docx` | МДК 05.02 | 21 практическая работа + 21 вопрос к зачёту |

### Как сгенерировать ПЕРЕЧЕНЬ (для ИИ-ассистента)

1. **Прочитать методику:** [`ПЕРЕЧЕНЬ_INSTRUCTIONS.md`](ПЕРЕЧЕНЬ_INSTRUCTIONS.md) — покомпонентный разбор документа и алгоритм сборки.
2. **Изучить образцы** в папке `Перечни/` — выбрать ближайший по структуре (с курсовым проектом / без, 1 группа / 2 группы).
3. **Извлечь данные из РП** (`RP/`): разделы, темы, перечень практических и самостоятельных работ, вопросы к зачёту, компетенции.
4. **Подготовить JSON** в формате (планируется `scripts/data_perechen_example.json`).
5. **Сгенерировать** (когда `scripts/generate_perechen_docx.py` будет готов):
   ```bash
   python3 scripts/generate_perechen_docx.py --data data.json --output "Перечни/перечень МДК XX.XX.docx"
   ```
6. **Провалидировать** (когда `scripts/validate_perechen.py` будет готов).

> ⚠️ Алгоритм и скрипты для ПЕРЕЧНЯ сейчас на стадии обсуждения — см. [`ПЕРЕЧЕНЬ_INSTRUCTIONS.md`](ПЕРЕЧЕНЬ_INSTRUCTIONS.md).

## Формат выходных файлов

- **Формат:** DOCX (`.docx`) / DOC (`.doc`) — Times New Roman, A4 портрет.
- **Генерация:** `python-docx` для КТП (`scripts/generate_ktp_docx.py`); для ПЕРЕЧНЯ — планируется аналогичный скрипт.
- **Справочные файлы** (`template_ktp.md`, `sample_ktp_example.md`, `ПЕРЕЧЕНЬ_INSTRUCTIONS.md`) — для ИИ при подготовке данных.
- **Итоговая строка КТП Таблицы 2:** «Итого» с суммами часов и практики.
