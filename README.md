# Автоматическая генерация КТП из РП

## О проекте

Данный репозиторий предназначен для автоматической генерации **календарно-тематических планов (КТП)** для междисциплинарных курсов (МДК) на основе исходных рабочих программ (РП) профессиональных модулей (ПМ).

**Цель:** создание КТП для различных МДК  ГБПОУ РО «Сальский индустриальный техникум» (СИТ).

## Состав репозитория

```
/
├── README.md                     # Общее описание проекта и инструкция по использованию
├── logic.md                      # ГЛАВНЫЙ ФАЙЛ – полная логика и правила генерации КТП
├── template_ktp.md               # Шаблон КТП в текстовом формате (пустая заготовка)
├── sample_ktp_example.md          # Универсальный эталон КТП (формат и правила заполнения)
├── RP/                           # Исходные рабочие программы (РП)
│   ├── РП_ПМ_03_КИП.txt          # Рабочая программа ПМ.03 (конвертирована в текст)
│   └── (другие РП при добавлении)
├── KTP/                          # Папка для сгенерированных КТП
│   ├── МДК_03_01_КТП.md          # Сгенерированный КТП для МДК 03.01
│   ├── МДК_03_02_КТП.md          # Сгенерированный КТП для МДК 03.02
│   ├── МДК_03_03_КТП.md          # Сгенерированный КТП для МДК 03.03
│   └── (другие КТП при генерации)
└── scripts/                      # Вспомогательные скрипты
    └── parse_rp.py               # Скрипт для парсинга РП и извлечения данных о МДК
```

## Как использовать

### Для ИИ-ассистента (основной сценарий)

1. **Прочитать инструкции:** открыть и внимательно изучить файл `logic.md` — он содержит полную пошаговую логику генерации КТП.
2. **Изучить шаблон:** открыть `template_ktp.md` — это пустая заготовка, которую нужно заполнить.
3. **Посмотреть эталон:** открыть `sample_ktp_example.md` — универсальный пример, показывающий формат и правила заполнения КТП для любой РП.
4. **Прочитать исходные данные:** открыть все файлы из папки `RP/` (текстовые версии рабочих программ).
5. **Генерировать КТП:** для каждого МДК, найденного в РП:
   - Извлечь темы, часы, практические занятия из таблиц раздела 2.2 РП.
   - Сформировать список занятий согласно правилам из `logic.md`.
   - Заполнить титульный лист и таблицу по шаблону.
   - Сохранить результат в `KTP/МДК_XX_YY_КТП.md`.
6. **Проверить итоги:** сравнить суммарное количество часов с плановым объёмом МДК из РП.

### Для человека

- Папка `RP/` содержит исходные рабочие программы в текстовом формате (.txt).
- Папка `KTP/` содержит сгенерированные КТП в формате Markdown (.md).
- Markdown-файлы можно конвертировать в DOCX любым удобным инструментом (Pandoc, онлайн-конвертер и т.д.).
- Скрипт `scripts/parse_rp.py` помогает извлечь структурированные данные из РП.

## Формат выходных файлов

- **Формат:**  DOCX.
- **Нумерация файлов:** `МДК_XX_YY_КТП.md`, где `XX` — номер ПМ, `YY` — номер МДК.
- **Таблицы:** с разделителями `|` и выравниванием колонок.
- **Итоговая строка:** «Итого» с суммой часов в конце основной таблицы.

## Исходные данные

- **Учебное заведение:** ГБПОУ РО «Сальский индустриальный техникум» (СИТ)
- **Исходные РП:** рабочие программы профессиональных модулей в папке `RP/`
