# Автоматическая генерация КТП из РП

## О проекте

Данный репозиторий предназначен для автоматической генерации **календарно-тематических планов (КТП)** для междисциплинарных курсов (МДК) на основе исходных рабочих программ (РП) профессиональных модулей (ПМ).

**Цель:** создание КТП для различных МДК ГБПОУ РО «Сальский индустриальный техникум» (СИТ).

## Единственный эталон

**`KTP/КТП МДК 05.02 М2 курс.docx`** — золотой стандарт оформления. Любой сгенерированный КТП должен быть структурно идентичен ему:

- Титульный лист: `МИНИСТЕРСТВО ОБРАЗОВАНИЯ РОСТОВСКОЙ ОБЛАСТИ` (без «общего и профессионального»)
- **7 таблиц**: УТВЕРЖДАЮ (без рамки), Таблица 1, Таблица 2, 2а, 2б, 2в, 2г
- **Таблица 1** — распределение часов: 12 колонок, 4-строчная шапка с объединениями, 12 строк
- **Таблица 2** — содержание обучения: **11 колонок** (включая ОК, ПК, ФИО преподавателя), шапка 3 строки + номерная
- **Таблица 2г (ЭИ)** — электронные источники с 5-й колонкой `URL (ссылка)`
- **Без заливки ячеек** (все ячейки белые), Times New Roman: титульник 12pt, таблицы 10pt
- Строка аттестации в Таблице 2: номер, название, 2 часа — остальные графы пустые

## Как использовать

### Для ИИ-ассистента (основной сценарий)

1. **Прочитать инструкции:** `KTP_INSTRUCTIONS.md` (методика) и `logic.md` (полная логика).
2. **Изучить эталон:** `KTP/КТП МДК 05.02 М2 курс.docx` — структура, шрифты, тексты шапок.
3. **Изучить шаблоны:** `template_ktp.md` (заготовка), `sample_ktp_example.md` (правила заполнения).
4. **Извлечь данные из РП** (`RP/`): темы, часы, занятия, литература, оснащение.
5. **Подготовить JSON** в формате `scripts/data_05_02_example.json`.
6. **Сгенерировать:**
   ```bash
   python3 scripts/generate_ktp_docx.py --data data.json --output "KTP/КТП МДК 05.02 М3 курс.docx"
   ```
7. **Провалидировать (обязательно):**
   ```bash
   python3 scripts/validate_ktp.py --doc "KTP/КТП МДК 05.02 М3 курс.docx" --data data.json
   ```
8. **Сохранить** с правильным именем в `KTP/`.

### Имя выходного файла

```
КТП МДК [код МДК] М[номер курса] курс.docx
```
Примеры: `КТП МДК 05.02 М2 курс.docx`, `КТП МДК 03.01 М3 курс.docx`, `КТП МДК 02.01 М4 курс.docx`

### Для человека

- Папка `RP/` содержит исходные рабочие программы.
- Папка `KTP/` содержит КТП в формате DOCX.
- Скрипт `scripts/generate_ktp_docx.py` генерирует `.docx` из JSON-данных строго по эталону.
- Скрипт `scripts/validate_ktp.py` проверяет суммы часов, структуру таблиц, свежесть литературы.

## Формат выходных файлов

- **Формат:** DOCX (`.docx`), Times New Roman, A4 портрет.
- **Генерация:** `python-docx` (скрипт `scripts/generate_ktp_docx.py`).
- **Справочные файлы** (`template_ktp.md`, `sample_ktp_example.md`) — для ИИ при подготовке данных.
- **Итоговая строка:** «Итого» с суммами часов и практики в конце Таблицы 2.

## Исходные данные

- **Учебное заведение:** ГБПОУ РО «Сальский индустриальный техникум» (СИТ)
- **Исходные РП:** рабочие программы профессиональных модулей в папке `RP/`
