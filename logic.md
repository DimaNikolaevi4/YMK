# Логика генерации календарно-тематического плана (КТП) из рабочей программы (РП)

## Полное руководство для ИИ-ассистента

Данный файл содержит **исчерпывающую пошаговую инструкцию** для автоматической генерации КТП на основе данных из рабочих программ профессиональных модулей. ИИ должен следовать каждому шагу строго последовательно, не пропуская ни одного правила.

---

## 1. Общие принципы

### 1.1. Исходные данные

- **Рабочие программы (РП)** находятся в папке `RP/`. Каждая РП — это текстовый файл (`.txt`), конвертированный из оригинального документа `.doc`.
- Каждая РП описывает один **профессиональный модуль (ПМ)**, который может содержать один или несколько **междисциплинарных курсов (МДК)**.
- Для каждого МДК необходимо создать отдельный КТП.

### 1.2. Выходные данные

- Для каждого МДК создаётся один файл КТП в формате **DOCX** (`.docx`).
- Файл сохраняется в папку `KTP/` с именем по шаблону: `МДК_XX_YY_КТП.docx`, где:
  - `XX` — номер ПМ (например, `03`)
  - `YY` — номер МДК в рамках ПМ (например, `01`, `02`, `03`)
- Для генерации `.docx` использовать скрипт `scripts/generate_ktp_docx.py` или библиотеку `python-docx` напрямую.
- Файлы `template_ktp.md` и `sample_ktp_example.md` являются **справочными** (для ИИ), а не выходными форматами.

### 1.3. Эталонный пример

- Файл `sample_ktp_example.md` содержит универсальный эталон КТП, не привязанный к конкретной профессии. Он демонстрирует формат всех таблиц, правила заполнения граф и структуру документа.
- При возникновении вопросов о формате — обращаться к эталону.
- Файл `template_ktp.md` — пустая заготовка, которую нужно заполнить данными из РП.

## 2. Порядок обработки одной РП

### Шаг 1. Определить перечнь МДК в РП

1. Найти в РП раздел **«Контроль знаний по профессиональному модулю»** (обычно в паспорте модуля, п. 1.3).
2. В таблице контроля знаний найти все строки, начинающиеся с «МДК» — это и есть междисциплинарные курсы, для которых нужно создать КТП.
3. Для каждого МДК записать:
   - **Код и полное наименование** (например, «МДК 03.01 Технология эксплуатации контрольно-измерительных приборов и систем автоматики»)
   - **Форму промежуточной аттестации** (дифференцированный зачёт, экзамен и т.д.)

### Шаг 2. Извлечь суммарные часы по каждому МДК

1. Найти раздел **«3.1. Тематический план профессионального модуля»**.
2. В таблице тематического плана найти строку с кодом МДК (например, «МДК 03.01»).
3. Извлечь из этой строки:
   - **Общий объём (всего часов)** — общее количество часов на МДК.
   - **Часы во взаимодействии с преподавателем** — объём аудиторной нагрузки.
   - **Часы теоретического обучения** — объём лекционных занятий.
   - **Часы лабораторных работ и практических занятий** — объём практической подготовки.
   - **Самостоятельная работа** — если есть (обычно для КТП не используется).

> **Важно:** Часы самостоятельной работы **НЕ включаются** в КТП. КТП содержит только аудиторные занятия (теория + практика).

### Шаг 3. Извлечь темы и часы из раздела «Структура и содержание»

1. Найти раздел **«3.2. Содержание обучения по профессиональному модулю»** (или «2.2» в некоторых РП).
2. Этот раздел содержит таблицу (или несколько таблиц), где для каждого МДК перечислены:
   - **Темы** с указанием часов (теория и практика).
   - **Содержание тем** — краткое описание того, что изучается.
   - **Практические занятия** — если выделены отдельной строкой.
   - **Лабораторные работы** — если есть.

3. Для каждой темы извлечь:
   - Номер и наименование темы (например, «Тема 1.1 Основы метрологии и поверка средств измерений»)
   - Общее количество часов на тему
   - Количество часов теории
   - Количество часов практики (если указано отдельно)

### Шаг 4. Определить вид каждого занятия

На основе извлечённых данных разделить занятия на типы:

| Тип занятия | Признак в РП | Обозначение в КТП |
|---|---|---|
| **Теоретическое (урок)** | Часы указаны в колонке «теоретическое обучение» | Урок |
| **Практическое занятие** | Имеет пометку «Практическое занятие» или часы в колонке «практические занятия» | Практ. занятие |
| **Лабораторная работа** | Имеет пометку «Лабораторная работа» | Лаб. работа |

## 3. Правила формирования занятий

### 3.1. Длительность занятия

- Каждое занятие (пара) **всегда** длится **2 академических часа**.
- Если на тему выделено 2 часа — это **одно занятие**.
- Если на тему выделено 4 часа — это **два занятия**.
- Если на тему выделено 6 часов — это **три занятия**.
- И так далее.

### 3.2. Разбивка теоретических тем

- Если на теоретическую тему выделено **ровно 2 часа** — создаётся одно занятие с полным названием темы.
- Если на теоретическую тему выделено **более 2 часов** — тема разбивается на несколько занятий с добавлением номера части:
  - Пример: тема «Основы метрологии» на 4 часа:
    - Занятие 1: «Тема 1.1 Основы метрологии и поверка средств измерений (часть 1)»
    - Занятие 2: «Тема 1.1 Основы метрологии и поверка средств измерений (часть 2)»
- **Исключение:** если в РП тема уже разбита на подтемы (отдельные строки с номерами 1, 2, 3...) — использовать названия подтем из РП, не добавлять «(часть N)».

### 3.3. Практические занятия

- Практические занятия берутся **напрямую из РП** с их оригинальными названиями.
- Если в РП есть нумерация практических занятий (например, «Практическое занятие №1») — **сохранить её**.
- Если в РП практические занятия не пронумерованы — **нумеровать последовательно** в рамках МДК (начиная с №1).
- Если на практическое занятие отведено 4 часа — это **два занятия** с одинаковым названием (или с добавлением «(часть 1)» и «(часть 2)»).
- Если 2 часа — **одно занятие**.

### 3.4. Лабораторные работы

- Оформляются **аналогично практическим занятиям**.
- Вид учебного занятия: «Лаб. работа».
- Нумерация — из РП или сквозная в рамках МДК.

### 3.5. Самостоятельная работа

- Строки с «Самостоятельной (внеаудиторной) работой» из РП **полностью игнорируются** — они не включаются в КТП.
- КТП содержит только аудиторные занятия.

## 4. Правила заполнения граф КТП

КТП содержит основную таблицу (Таблица 2) со следующими графами:

| № графы | Название графы | Правила заполнения |
|---|---|---|
| 1 | **№ п/п** | Сквозная нумерация всех занятий по порядку: 1, 2, 3, ... Нумерация не сбрасывается при смене темы. |
| 2 | **Наименование разделов, тем** | См. раздел 4.1 ниже. |
| 3 | **Кол-во часов** | Всегда **2** для каждого конкретного занятия (пары). Исключение: если в РП на занятие указано иное нечётное количество — уточнить, но обычно все занятия по 2 часа. |
| 4 | **В форме практической подготовки** | См. раздел 4.2 ниже. |
| 5 | **Вид учебного занятия** | См. раздел 4.3 ниже. |
| 6 | **Оснащение занятий** | См. раздел 4.4 ниже. |
| 7 | **Задание для студентов** | См. раздел 4.5 ниже. |
| 8 | **Примечание** | См. раздел 4.6 ниже. |

### 4.1. Графа «Наименование разделов, тем»

Эта графа содержит несколько типов строк:

**а) Заголовочная строка МДК** (одна строка в начале):
```
| | МДК 03.01 Технология эксплуатации контрольно-измерительных приборов и систем автоматики | [общие часы] | [практ. подготовка] | | | | |
```
- Общие часы берутся из таблицы 3.1 РП.
- Практическая подготовка — сумма часов практики из таблицы 3.1.

**б) Заголовочная строка темы** (перед занятиями по теме):
```
| | Тема 1.1 Основы метрологии и поверка средств измерений | [часы темы] | [практ. часы темы] | | | | |
```
- Часы темы — общее количество часов на эту тему (из РП).
- Практические часы — только практическая часть (из РП).

**в) Строка занятия (теория):**
```
| 1 | Тема 1.1 Основы метрологии и поверка средств измерений (часть 1) | 2 | | Урок | ... | ... | ... |
```

**г) Строка занятия (практика):**
```
| 5 | Практическое занятие №1: Название практической работы | 2 | 2 | Практ. занятие | ... | ... | ... |
```
- Если в РП практическое занятие имеет номер — использовать его.
- Если в РП нет номера — нумеровать самостоятельно в рамках МДК.

### 4.2. Графа «В форме практической подготовки»

- Ставится **«2»** (или «да»), если занятие является практическим или лабораторным.
- Для теоретических занятий — **пусто** (если в РП нет пометки о практической подготовке).
- Если в РП для конкретного теоретического занятия указана практическая подготовка — поставить **«2»**.

> **Правило из примера:** в МДК 03.01 из РП ПМ.03 практическая подготовка составляет 107 часов из 129 (большинство занятий). Следовательно, **почти все занятия** будут помечены как практическая подготовка.

### 4.3. Графа «Вид учебного занятия»

| Тип | Значение |
|---|---|
| Теоретическое занятие | `Урок` |
| Практическое занятие | `Практ. занятие` |
| Лабораторная работа | `Лаб. работа` |

### 4.4. Графа «Оснащение занятий»

Использовать коды из таблиц материально-технического обеспечения:
- **Для теоретических занятий:** `ОИ1, ОИ2` (основные источники), `ДИ1, ДИ2` и т.д. (дополнительные источники) — указать номера учебников из списка литературы.
- **Для практических занятий:** `№3, 2а` (методические указания + код из таблицы оснащения) или конкретное оборудование, если оно указано в РП для данной темы.

Коды источников берутся из:
- Таблицы «Основные источники (ОИ)» — нумерация ОИ 1, ОИ 2, ...
- Таблицы «Дополнительные источники (ДИ)» — нумерация ДИ 1, ДИ 2, ...

### 4.5. Графа «Задание для студентов»

- **Для теоретических занятий:** указать учебник и страницы, например: `Стр. 5-10`. Страницы можно взять из содержания темы в РП или распределить пропорционально.
- **Для практических занятий:** `Методические указания к практической работе №X` (или `Метод.указания`).

### 4.6. Графа «Примечание»

| Ситуация | Значение |
|---|---|
| Первое занятие МДК | `Вх.контр` (входной контроль) |
| Теоретическое занятие (не первое) | `Текущий контроль` |
| Практическое/лабораторное занятие | `Защита пр.работы` |
| Последнее занятие раздела/темы | `Промежуточный контроль` (по усмотрению) |

> **Примечание:** в примере КТП входной контроль ставится на первое занятие каждой новой темы, а не только на самое первое занятие МДК. Это допустимый вариант оформления.

## 5. Формирование титульного листа КТП

Титульный лист заполняется по следующим правилам:

### 5.1. Реквизиты учебного заведения (фиксированные)

```
МИНИСТЕРСТВО ОБЩЕГО И ПРОФЕССИОНАЛЬНОГО ОБРАЗОВАНИЯ РОСТОВСКОЙ ОБЛАСТИ
ГОСУДАРСТВЕННОЕ БЮДЖЕТНОЕ ПРОФЕССИОНАЛЬНОЕ ОБРАЗОВАТЕЛЬНОЕ УЧРЕЖДЕНИЕ РОСТОВСКОЙ ОБЛАСТИ
«САЛЬСКИЙ ИНДУСТРИАЛЬНЫЙ ТЕХНИКУМ»
(ГБПОУ РО «СИТ»)
```

### 5.2. Утверждающие подписи

```
УТВЕРЖДАЮ
Зам. директора ГБПОУ РО «СИТ» ______________ Т.В. Якимова
«____» ______________ 20 ____ г.
```

### 5.3. Основные параметры (заполняются из РП)

| Поле | Источник данных |
|---|---|
| **Семестр** | Из РП (если указан) или из учебного плана. Если не найден — оставить `__` для заполнения вручную. |
| **Учебный год** | `20__-20__ уч. год` (шаблон, заполняется вручную). |
| **Курс** | Определяется по семестру (семестр 5 = курс 3 и т.д.). Если неясно — оставить `__`. |
| **Группа** | `_________` (заполняется вручную). |
| **Профессиональный модуль** | Полное наименование ПМ из РП (включая код, например: «ПМ.03 Техническое обслуживание и эксплуатация приборов и систем автоматики...»). |
| **Междисциплинарный курс** | Полное наименование МДК из РП (например: «МДК 03.01 Технология эксплуатации контрольно-измерительных приборов и систем автоматики»). |
| **Профессия** | Полное наименование профессии с кодом (из РП). |
| **Объём образовательной программы** | Общее количество часов на МДК (из таблицы 3.1 РП). |
| **В том числе в форме практической подготовки** | Часы практической подготовки для данного МДК (из таблицы 3.1). |
| **Учебная нагрузка во взаимодействии с преподавателем** | Обычно равна общему объёму (если нет самостоятельной работы в рамках МДК). |
| **Теоретическое обучение** | Часы теории из таблицы 3.1. |
| **Практические занятия** | Часы практики из таблицы 3.1. |
| **Лабораторные занятия** | Если есть — из таблицы 3.1, иначе `_____`. |
| **Курсовая работа/проект** | Если есть — из таблицы 3.1, иначе `_____`. |
| **Самостоятельная работа** | Если есть — из таблицы 3.1, иначе `_____`. |
| **Промежуточная аттестация** | Форма аттестации из таблицы «Контроль знаний» (дифференцированный зачёт, экзамен и т.д.). |

### 5.4. Подписи внизу титульного листа

```
Составлен в соответствии с рабочей программой ПМ __, утверждённой __________________
                         (дата утверждения)

Рассмотрен на заседании цикловой комиссии _____________________________ дисциплин
Протокол №_______от________________20_____ года
Председатель цикловой комиссии ___________________________/Ткаченко А.Н./
```

## 7. Таблица 2. Содержание обучения по профессиональному модулю

Это основная таблица КТП. Структура:

1. **Заголовок таблицы:** `Содержание обучения по профессиональному модулю Таблица 2`
2. **Строка заголовков колонок:** `№ п/п | Наименование разделов, тем... | Кол-во часов | ...`
3. **Заголовочная строка МДК:** (пустой №, название МДК, общие часы, часы практики, остальные графы пустые).
4. **Для каждой темы:**
   - Заголовочная строка темы (пустой №, название темы, часы темы, часы практики, остальные пустые).
   - Строки занятий (теория и практика) с заполненными всеми графами.
5. **Итоговая строка:**

```
| | Итого: | [сумма часов] | [сумма практической подготовки] | | | | | |
```

> **Критически важно:** сумма часов в строке «Итого» должна **строго совпадать** с общим объёмом МДК из таблицы 3.1 РП (за вычетом самостоятельной работы, если она есть).

## 9. Итоговая проверка (ОБЯЗАТЕЛЬНЫЙ ЭТАП)

После заполнения всей таблицы 2 необходимо выполнить следующие проверки:

### 9.1. Проверка суммы часов

1. Просуммировать все значения в графе «Кол-во часов» (только строки занятий, не включая заголовочные строки тем и МДК).
2. Сравнить полученную сумму с общим объёмом МДК из РП.
3. **Если суммы не совпадают:**
   - Проверить, все ли темы учтены.
   - Проверить, не пропущены ли практические занятия.
   - Проверить, правильно ли разбиты темы на части (каждая часть = 2 часа).
   - Скорректировать: добавить недостающие занятия или убрать лишние.

### 9.2. Проверка практической подготовки

1. Просуммировать значения в графе «В форме практической подготовки».
2. Сравнить с плановым объёмом практической подготовки из РП.
3. При расхождении — скорректировать.

### 9.3. Проверка нумерации

1. Убедиться, что нумерация занятий сквозная и без пропусков.
2. Убедиться, что номера практических занятий соответствуют РП (если в РП есть нумерация).

### 9.4. Проверка полноты

1. Все темы из РП должны быть представлены в КТП.
2. Все практические занятия из РП должны быть включены.
3. Самостоятельная работа из РП **НЕ должна** присутствовать в КТП.

## 10. Обработка нескольких РП

### 10.1. Общий порядок

1. Получить список всех файлов в папке `RP/`.
2. Для каждого файла РП выполнить шаги 1–9 из данного руководства.
3. Каждый сгенерированный КТП сохранить в папку `KTP/` с уникальным именем.

### 10.2. Конфликты и дублирование

- Если в разных РП упоминается один и тот же МДК — использовать данные из той РП, где этот МДК является основным.
- Если для МДК уже существует КТП в папке `KTP/` — перезаписать его (новая версия).

### 10.3. Именование файлов

Шаблон имени: `МДК_XX_YY_КТП.docx`

Примеры:
- `МДК_03_01_КТП.docx` — КТП для МДК 03.01
- `МДК_03_02_КТП.docx` — КТП для МДК 03.02
- `МДК_03_03_КТП.docx` — КТП для МДК 03.03
