## 6. Как вносить данные в КТП (механика)

1. Найденное оглавление записывается в этот файл (раздел 3/4) и в `scripts/lit_pages_01_02.json`
   (поля `owner_ai_ranges` / `verified_toc_used`), с пометкой достоверности и URL источника.
2. После подтверждения владельцем (или сверки с бумажным изданием) данные переносятся в
   `verified_toc_used` и вносятся в КТП скриптом: `python3 scripts/fill_pages_01_02.py`
   (формат кол. 9: «ОИ N, с. X-Y»; практические остаются «Метод. указания»).
3. Обязательные проверки после внесения: `python3 scripts/validate_ktp.py` (29 проверок), контроль
   последовательности диапазонов внутри темы (без пересечений), QA-прогон `recalc/audit/scan/validate`.
4. Файл коммитится на GitHub: он же — резервная копия, он же — источник для следующей итерации.
