## КОНТЕКСТ

Составляется КТП МДК 01.02 «Обеспечение контроля, учета и регулирования бесперебойной поставки
электрической энергии потребителям» (ПМ.01, специальность 08.02.09 «Монтаж, наладка и эксплуатация
электрооборудования промышленных и гражданских зданий», группа М-21, семестр 3, 2026–2027 уч. год).
Для теоретических занятий в столбце 9 «Задания для студентов» нужно указать **реальные страницы
учебников** по формату «ОИ N, с. X-Y». Заполнение столбца 9 возможно ТОЛЬКО по реальным оглавлениям
книг с номерами страниц. **Выдумывать страницы запрещено.**

   `books.ru`, `ozon.ru`

## ОГРАНИЧЕНИЯ (КРИТИЧНО)

1. **НЕ ВЫДУМЫВАТЬ СТРАНИЦЫ.** Если оглавление не найдено — так и писать: «не найдено».
2. Каждый диапазон страниц должен сопровождаться **URL источника**, где он найден.
3. Если найдены противоречивые оглавления разных изданий — привести ОБА с указанием издания/года/объёма.
4. Не смешивать страницы разных изданий одной книги.
5. Предпочтение: официальные сайты издательств > ЭБС > магазины с фрагментами > полнотекстовые PDF >
   учебные сайты > форумы.
6. Результат должен покрывать ВСЕ источники списка — даже если ответ «не найдено».
