## Как заполнить (3 варианта)

1. **Владелец присылает содержания книг** (фото/скан оглавления или электронные версии) → точная привязка тем к страницам, правка 27 ячеек Т2 КТП.
2. **Глубокий поиск оглавлений** (как для МДК 05.02 — `docs/agent_task_search_book_pages.md`): расширенный поиск по библиотечным сервисам (ЭБС Юрайт, Лань, rusneb.ru), сопоставление глав с темами.
3. **Разбиение по образцу эталона**: если основной учебник один (ОИ 1 Конюхова, ~400 с.) — равномерные диапазоны по блокам тем (как в эталоне 05.02: непрерывные «Стр. 79-93», «Стр. 94-108»…). Нужна только команда владельца.
