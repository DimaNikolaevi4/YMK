## ЧТО НУЖНО СДЕЛАТЬ (ПОРЯДОК ДЕЙСТВИЙ)

### Шаг 1. Поиск оглавлений

Для **каждой из трёх книг** выполнить веб-поиск по:
- Полному названию книги + автор + издательство + год
- Ключевые слова: "содержание", "оглавление", "table of contents"

**Источники для поиска**:
- `books.ru` / `bookvoed.ru` / `chitai-gorod.ru` — часто показывают оглавление
- `biblio-online.ru` / `urait.ru` — электронные библиотеки СПО, могут иметь фрагменты с оглавлением
- `ozon.ru` / `wildberries.ru` / `litres.ru` — иногда есть «посмотреть фрагмент» или «читать образец»
- `e.lanbook.com` (издательство Лань) — если книга там есть
- `academia-moscow.ru` (издательство Академия) — официальный сайт издательства
- Поиск по `site:pdf` или `site:doc` для поиска полных текстов
- `studfile.net` / `studmed.ru` / `infourok.ru` — учебные материалы, где могут быть выложены фрагменты

### Шаг 2. Извлечение структуры оглавления

Для каждой найденной книги составить список:
```
РАЗДЕЛ / ГЛАВА → Название темы → Номера страниц
```

Пример ожидаемого формата:
```
Глава 1. Охрана труда при электромонтажных работах ............... 5-18
  1.1. Правила техники безопасности .................................. 5-10
  1.2. Первая помощь при поражении током ........................ 11-18
Глава 2. Осветительные установки .................................... 19-45
  ...
```

### Шаг 3. Сопоставление тем КТП с оглавлениями книг

Для **каждой темы КТП** (2.1–2.8) определить:
1. **Какая книга** лучше всего покрывает данную тему (ОИ2, ОИ3 или ОИ4)
2. **Какие разделы/главы** в этой книге соответствуют теме
3. **Номера страниц**, на которых расположен этот раздел

Правила сопоставления:
- Тема может покрываться **одной книгой** для всех занятий или **разными книгами** для разных тем
- Для тем, разбитых на несколько занятий (часть 1, 2, 3...), нужно указать **диапазон страниц на каждое занятие**
- Если в книге на тему отведено 20 страниц, а занятий 6 — разбить примерно поровну (по 3-4 страницы на занятие)
- Страницы должны идти **последовательно**, без пропусков и пересечений

### Шаг 4. Формирование результата

Вывести результат в виде **таблицы**:

```
| Тема КТП | Занятие | Книга (код) | Раздел книги | Страницы |
|----------|---------|-------------|--------------|----------|
| 2.1 | Безопасность труда... | ОИ2 | Гл.1 «Охрана труда...» | Стр. 5-18 |
| 2.2 ч.1 | ...осветительных... | ОИ3 | §3.1 «Виды освещения» | Стр. 22-28 |
| 2.2 ч.2 | ...осветительных... | ОИ3 | §3.2 «Монтаж светильников» | Стр. 29-35 |
| ... | ... | ... | ... | ... |
```

## ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ

### Текущий основной источник (ОИ1) — нужно заменить или дополнить
- **ОИ 1**: Григорьева С.В. «Общая технология электромонтажных работ: учебник для СПО», М.: ИЦ "Академия", 2020
- Сейчас в КТП указан только ОИ1 с **выдуманными страницами** (Стр. 5-12, 13-22, 23-30...) — это НЕ реальное оглавление

### Стратегия
1. Найти оглавление ОИ2 (Нестеренко) — **приоритет №1**, так как название лучше всего совпадает с МДК 05.02
2. Если ОИ2 не покрывает все темы — дополнить ОИ3 (Сидорова) для тем ремонта (2.6–2.8)
3. ОИ4 (Ярочкина) — использовать при необходимости для тем наладки/проверки
4. Возможен вариант: **одна книга на все темы** или **комбинация 2-3 книг** (для разных тем — разные книги)

### Формат страниц в КТП
- В столбце 9 страницы указываются в формате: **`Стр. X-Y`** (например, `Стр. 5-18`)
- Для одного занятия — один диапазон страниц

## ОЖИДАЕМЫЙ РЕЗУЛЬТАТ

Агент должен вернуть:

1. **Найденные оглавления** каждой из трёх книг (полный список разделов с номерами страниц, сколько удалось найти)

2. **Таблицу сопоставления** — для каждого из 26 теоретических занятий:
   - Тема занятия (из КТП)
   - Код книги (ОИ2 / ОИ3 / ОИ4)
   - Название раздела/главы из книги
   - Диапазон страниц (в формате `Стр. X-Y`)

3. **Примечания**: если для каких-то тем не удалось найти точные страницы — указать это и предложить наиболее вероятный диапазон на основе структуры книги

## ОГРАНИЧЕНИЯ

- Если полное оглавление книги не найдено — использовать **любые доступные фрагменты**: фрагмент оглавления, аннотацию с перечислением глав, отзывы читателей с упоминанием содержания, учебные планы с ссылками на страницы
- Если книга не найдена вообще — явно указать: «Книга [название] не найдена в открытых источниках»
- Не выдумывать страницы! Если не найдено — пометить как «не найдено»
- Предпочтение источникам: официальные сайты издательств > электронные библиотеки > книжные магазины с фрагментами > учебные сайты > форумы
