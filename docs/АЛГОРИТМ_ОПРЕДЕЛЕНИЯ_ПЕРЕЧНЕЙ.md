# Алгоритм определения перечней аттестации

> **Назначение:** единое правило, по которому определяется, сколько перечней материалов
> готовить и какие именно. Документ для преподавателя и для ИИ-агента: следующий год
> начинается не с нуля, а с этого файла.
>
> **Статус:** действует с 2026-10-25. Проверен на учебном плане 2026-2027 (нечётные семестры).
> **Источник истины:** оригиналы УП в `учебные_планы/исходники/` (`.doc`, `.docx`).
> Файлы `учебные_планы/*.md` — только навигация; при любом расхождении верен оригинал.

## 1. Когда применять

- Нужно ответить на вопрос «какие перечни готовить для N семестра».
- Меняется учебный план, нагрузка или форма аттестации.
- ИИ-агент собирает очередной перечень и должен решить, существует ли он вообще.

## 2. Входные данные

| Что | Откуда | Зачем |
|---|---|---|
| Учебный план группы | `учебные_планы/исходники/` | формы аттестации по семестрам |
| Нагрузка преподавателя | `нагрузка_2026-2027.md` | отсечь МДК, которые ведёт другой |
| Рабочая программа | `RP/01_Актуальные` | темы, работы, вопросы для самого перечня |
| КТП | `KTP/` | номера уроков для таблицы «Контроль знаний» |

## 3. Алгоритм — 7 шагов

### Шаг 1. Зафиксировать целевой семестр
Определить, какие семестры считаем. Например, нечётные 2026-2027 — это 3 и 5.
Всё, что аттестуется в 4, 6, 8, в расчёт не идёт.

### Шаг 2. Отфильтровать строки УП
По каждой группе оставить только строки МДК и ПА, у которых **в целевом семестре** стоит форма:
«Экзамены», «Зачёты», «Дифференцированные зачёты». Прочерк — строка выбывает.

### Шаг 3. Отфильтровать по нагрузке
МДК, который ведёт другой преподаватель, выбывает, даже если форма в нужном семестре есть.
Перечни готовятся только по своим МДК.

### Шаг 4. Проверить завершённость МДК
Если МДК идёт в нескольких семестрах и в целевом формы нет — перечень не готовится:
аттестация ждёт семестра завершения модуля.

### Шаг 5. Определить объект документа
| Что стоит в УП | Объект перечня |
|---|---|
| Диф. зачёт / зачёт / экзамен по конкретному МДК | этот МДК |
| КДЗ (комплексный диф. зачёт) | весь ПМ, объединяя все МДК, по которым он выставлен |
| ПА (экзамен по модулю, квалификационный) | ПМ целиком, отдельный документ |

### Шаг 6. Склеить и разделить
- несколько МДК с одним КДЗ → **один** сводный документ (правило комплексности);
- КДЗ/диф. зачёт по МДК и ПА в одном семестре → **два** документа (правило непоглощения);
- параллельные группы с одинаковой формой (С-21 и С-22) → **один** документ,
  два листа ознакомления.

### Шаг 7. Посчитать
Количество документов = число уникальных пар «объект × форма» в пределах параллели,
прошедших шаги 2–4.

```
для каждой группы:
  для каждой строки УП:
    если форма_в_семестре(строка, S) и строка.владелец == я:
      если строка == МДК и форма == КДЗ: ключ = (ПМ, "КДЗ")
      иначе если строка == МДК:          ключ = (МДК, форма)
      иначе если строка == ПА:           ключ = (ПМ, "ПА")
документы = уникальные ключи по параллели
```

## 4. Что в счёт не идёт

| Исключение | Почему |
|---|---|
| Практики УП и ПП | форма может стоять (у С-21/С-22 УП.02 и ПП.02 — диф. зачёт в 3 сем.), но перечень по практике не готовится |
| ГИА, курсовые, консультации | не формы промежуточной аттестации |
| МДК без формы в целевом семестре | часы есть, аттестации нет |
| Параллельная группа | не добавляет документ, только лист ознакомления |
| МДК не из своей нагрузки | готовит тот, кто ведёт |

## 5. Проверочный пример: 2026-2027, нечётные

| Группа | Строка УП | Форма в 3/5 | Решение |
|---|---|---|---|
| КИП-31 | МДК 02.01 | диф. зачёт, 5 | ✅ документ 1 |
| КИП-31 | ПА.02 | 6 сем. | ❌ чётный |
| КИП-31 | МДК 02.02, 02.03 | 6 сем. | ❌ чётный + не в нагрузке |
| С-21, С-22 | МДК 02.01 + 02.02 | КДЗ, 3 | ✅ документ 2 — один на два МДК |
| С-21, С-22 | ПА.02 | 3 | ✅ документ 3 — не поглощается КДЗ |
| С-21, С-22 | МДК 03.x | 4 | ❌ чётный |
| М-21 | МДК 01.02, 05.02 | 4 | ❌ чётный |
| ОТП-41 | МДК 04.02, 04.03 | 8 | ❌ чётный |

**Итог: 3 документа.**

1. Дифференцированный зачёт по МДК 02.01 — КИП-31, 5 семестр.
2. Комплексный дифференцированный зачёт по ПМ.02 — С-21, С-22, 3 семестр.
3. Экзамен по профессиональному модулю ПМ.02 — С-21, С-22, 3 семестр.

Этот пример — регресс-тест: если после изменения УП алгоритм даёт другой результат,
значит либо изменился план, либо в алгоритме ошибка. Проверять в таком порядке.

## 6. Типовые ошибки

| Ошибка | Правильно |
|---|---|
| Считать перечни «по МДК» | единица счёта — форма аттестации |
| Объединить КДЗ и экзамен по модулю в один документ | это два независимых документа |
| Размножить КДЗ по каждому МДК | один сводный документ на ПМ |
| Забыть исключить практики | УП.02/ПП.02 с диф. зачётом в счёт не идут |
| Взять данные из `.md`-выжимки | только оригинал УП из `исходники/` |
| Учесть МДК другого преподавателя | сначала фильтр по нагрузке |

## 7. Как обновлять

1. При смене учебного плана или нагрузки — заново пройти шаги 2–4.
2. Обновить раздел 5 (пример) под новый учебный год.
3. Зафиксировать дату и статус в шапке файла.
4. Если правило поменялось — сначала правится этот файл, потом реестр перечней.
